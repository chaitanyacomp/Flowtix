# Architectural Decision Records (ADR) Registry

Versioned registry of FT ERP Architectural Decision Records, governed by
[FT-PD-101 — Feature Governance, Change Control & Architectural Decision Records](../Chapter_02_Feature_Governance_Change_Control_and_Architectural_Decision_Records.md)
(§7 ADR governance, §12F knowledge preservation).

- **Identifier format:** `ADR-YYYY-NNN` (permanent, never reused).
- **Lifecycle:** Proposed → Accepted → Superseded / Rejected. Superseded ADRs are retained, never deleted (ADR-04).
- **Steward:** Product Architecture Board.
