# Quick Start Guide — Flowtix ERP v1.0.0

## In 15 minutes

1. **Install** using `01 Setup\Flowtix-ERP-Setup.exe` (see Installation Guide).
2. **Configure** database URL and JWT via `configure-env`.
3. **Open** `http://127.0.0.1:<PORT>/` and sign in as Administrator.
4. **Company Profile** — set legal name, GSTIN, address, logo.
5. **Masters** — Units (seeded), Locations, Customers, Suppliers, Items, BOM.
6. **First NORMAL sales order** — create → approve/open → plan → produce → QC → dispatch → bill.
